# Copper Loon partnership preview

From this directory run:

```bash
python3 -m http.server 8080
```

Open http://localhost:8080 in Chrome. Use a web server rather than opening index.html directly because the existing site uses root-relative asset paths.

Changes: index.html, static/css/home.css, and the new static/images/brand/great_lakes_logo.svg. The grow solution introduces the partnership; the following section explains both companies' roles and links to Great Lakes' Mission Control page. Existing contact page and JavaScript are unchanged.

Review desktop and mobile widths, both logos, partner link, demo, navigation, and image viewer before deployment. Browser visual testing was not available in the editing environment. Existing external fonts, icons, and Umami analytics remain; local browsing may record analytics events.
